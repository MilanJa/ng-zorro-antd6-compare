NG-ZORRO on Ant Design 6

Does NG-ZORRO render like Ant Design 6 when the v6 stylesheet is switched on?

Every mapped component, three ways: Ant Design 6.6.5's own React demo, the same NG-ZORRO demo under the opt-in v6 stylesheet, and the NG-ZORRO demo under the v4 stylesheet it ships today. Both v6 columns are styled by the same extracted CSS, so a difference between them is an NG-ZORRO DOM difference, not a theme difference. Demos are paired by name; sample text, dates and item counts can differ, so judge shape, colour, spacing and type rather than the words. The live view runs the real components in isolated frames, each with its own stylesheet, so you can open dropdowns and modals on both sides. The screenshot view holds the captures the port was verified against, including opened overlay states; click an image to enlarge it, then press space to flip between the antd and NG-ZORRO renders in place.
